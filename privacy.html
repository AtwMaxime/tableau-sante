Règles de confidentialité

Dernière mise à jour : 24 novembre 2026

Qui utilise cette application

Cette application est un outil personnel. Son seul utilisateur est son propriétaire, qui l'utilise pour consulter ses propres données de santé.

Données consultées

Avec l'autorisation explicite de l'utilisateur (OAuth Google), l'application lit en lecture seule via la Google Health API :

  • les données d'activité : pas, distance, calories, minutes actives, exercices ;
  • les mesures de santé : fréquence cardiaque, variabilité cardiaque, saturation en oxygène, fréquence respiratoire ;
  • les données de sommeil ;
  • les informations de profil et de réglages nécessaires à l'affichage.

L'application n'écrit, ne modifie et ne supprime aucune donnée dans le compte Google de l'utilisateur.

Stockage et utilisation

  • Les données sont enregistrées uniquement sur l'ordinateur personnel de l'utilisateur, dans une base locale.
  • Elles servent uniquement à afficher un tableau de bord personnel.
  • Aucune donnée n'est envoyée à un serveur tiers, vendue, partagée, ni utilisée pour de la publicité ou pour entraîner des modèles d'IA.

L'utilisation des données reçues des API Google respecte les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée (« Limited Use »).

Suppression et révocation

L'utilisateur peut retirer l'accès à tout moment depuis myaccount.google.com/permissions. Pour supprimer les données locales, il suffit d'effacer les fichiers de l'application sur l'ordinateur.

Contact

Pour toute question, ouvrez une demande (« issue ») sur le dépôt GitHub de ce site.
